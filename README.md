# Atlas Trung tâm Nghiên cứu, Đổi mới sáng tạo

Bản đồ toàn cầu (quả cầu 3D + lược đồ khu vực) và danh mục các mô hình trung tâm
nghiên cứu/CGCN/ĐMST của các đại học trên thế giới.

**Trạng thái:** bản demo (v0.2). 6 case điển hình đã đối chiếu nguồn công khai
(Stanford OTL, Cambridge Enterprise, KU Leuven, Lund, Tsinghua, NUS/BLOCK71 —
NUS đang chờ nguồn thay thế do file gốc lỗi). Danh mục mở rộng (~786 mục) là
roster rộng/nông tổng hợp từ nhiều nguồn công khai, chưa thẩm định từng mục.

Không dùng để trích dẫn chính thức.
